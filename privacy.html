GitHub Accelerator
隐私政策与数据使用说明
欢迎使用

GitHub Accelerator 是一款智能 GitHub 下载加速器，通过智能代理节点选择和 302 重定向，为您提供快速的 GitHub 资源下载体验。

在使用本扩展之前，请仔细阅读以下隐私政策。点击「同意」即表示您理解并接受本政策的所有内容。

数据收集说明

本扩展不会收集、存储或传输任何个人信息、浏览历史、凭证或敏感数据。不使用任何分析工具、Cookie 或跟踪技术。

扩展仅在本地浏览器存储中保存以下数据：

数据项 存储方式 用途
最优代理节点缓存 本地存储 缓存最优代理节点，2小时过期，避免重复测速
代理节点列表 本地存储 缓存可用代理节点列表及延迟结果
始终加速开关 本地存储 用户偏好设置，自动跳转不显示选择页面
会话临时禁用标记 本地存储 临时跳过当前会话的拦截
域名级偏好设置 本地存储 用户设置的每域名加速/直连偏好
即将添加的匿名统计功能

我们计划在未来版本中添加匿名使用统计功能，用于帮助我们了解扩展的使用情况并向社区展示服务成果。具体统计项如下：

统计项 说明 是否匿名
累计加速跳转次数 加速重定向被触发的总次数（简单计数） 是，仅聚合数字
累计安装/更新次数 扩展被安装或更新的总次数 是，仅聚合数字

我们绝对不会收集：

- 任何个人信息（姓名、邮箱、IP 地址等）

- 浏览历史或访问的 URL

- 下载的文件名或文件内容

- 浏览器书签、密码或任何敏感数据

- 任何可追溯到个人的标识符

统计数据仅用于了解扩展使用情况以及对外展示（如「累计加速突破 X 次」）。数据可能会提交至我们的服务器进行汇总，但绝不会传输任何个人身份信息。

网络请求说明

扩展会向以下地址发起网络请求：

目标地址 发送数据 用途
hubp.tbedu.top 无 获取可用代理节点列表
api.ipapi.is / api.ip.sb 无 检测地理位置（判断是否需要加速）
代理节点（如 gh.llkk.cc） 无 测速，下载测试资源
addon-analytics.hubp.org 匿名聚合计数 提交匿名统计数据用于汇总
