GitHub Accelerator
隐私政策与数据使用说明
欢迎使用

GitHub Accelerator 是一款智能 GitHub 下载加速器，通过智能代理节点选择和 302 重定向，为您提供快速的 GitHub 资源下载体验。

在使用本扩展之前，请仔细阅读以下隐私政策。点击「同意」即表示您理解并接受本政策的所有内容。

数据收集说明

本扩展不会收集、存储或传输任何个人信息、浏览历史、凭证或敏感数据。不使用任何 Cookie 或第三方跟踪技术。本扩展仅收集匿名聚合统计数据（详见下方「匿名统计功能」）。

扩展仅在本地浏览器存储中保存以下数据：

数据项 存储方式 用途
最优代理节点缓存 本地存储 缓存最优代理节点，2小时过期，避免重复测速
代理节点列表 本地存储 缓存可用代理节点列表及延迟结果
始终加速开关 本地存储 用户偏好设置，自动跳转不显示选择页面
会话临时禁用标记 本地存储 临时跳过当前会话的拦截
域名级偏好设置 本地存储 用户设置的每域名加速/直连偏好
匿名统计功能

本扩展已内置匿名使用统计功能，用于帮助我们了解扩展的使用情况并向社区展示服务成果。统计数据在本地累积后批量上报，具体统计项如下：

统计项 说明 是否匿名
累计加速跳转次数 加速重定向被触发的总次数（简单计数） 是，仅聚合数字
累计安装/更新次数 扩展被安装或更新的总次数 是，仅聚合数字
浏览器类型 Chromium 或 Firefox，用于按浏览器维度汇总 是，仅分类标识
扩展版本号 当前扩展版本，用于按版本维度汇总 是，仅版本号

我们绝对不会收集：

- 任何个人信息（姓名、邮箱、IP 地址等）

- 浏览历史或访问的 URL

- 下载的文件名或文件内容

- 浏览器书签、密码或任何敏感数据

- 任何可追溯到个人的标识符

统计数据仅用于了解扩展使用情况以及对外展示（如「累计加速突破 X 次」）。数据会在本地累积后批量提交至我们的服务器（addon-analytics.hubp.org）进行汇总，但绝不会传输任何个人身份信息。如果您无法接受本隐私政策，建议直接卸载本扩展。

网络请求说明

关于地理位置检测的提示：

为判断您是否位于中国大陆（决定是否需要加速），扩展会通过 Cloudflare 边缘节点的 /cdn-cgi/trace 端点获取您的 IP 所属地区。该端点直接由 Cloudflare 网络应答，不经过任何第三方服务器。

检测顺序：优先请求自有域名 gh.dpik.top（您的 IP 不会发送给任何第三方）；如不可用则依次回退到 visa.cn、cloudflare.com（此时您的 IP 会暴露给 Cloudflare/Visa）；最后回退到第三方服务（api.ipapi.is / api.ip.sb，此时您的 IP 会暴露给上述第三方）。

我们本身不会存储、记录或上报您的 IP 地址，也无法控制第三方如何处理该信息。如果您无法接受本隐私政策，建议直接卸载本扩展。

扩展会向以下地址发起网络请求：

目标地址 发送数据 用途
hubp.tbedu.top 无 获取可用代理节点列表
gh.dpik.top/cdn-cgi/trace（自有域名） IP 地址（仅用于判断所属地区，不存储、不记录） 检测地理位置（优先，数据不经过第三方）
www.visa.cn / www.cloudflare.com 的 /cdn-cgi/trace IP 地址（仅用于判断所属地区，不存储、不记录） 检测地理位置（兜底 1，由 Cloudflare/Visa 应答）
api.ipapi.is / api.ip.sb IP 地址（仅用于判断所属地区，不存储、不记录） 检测地理位置（兜底 2，仅当前两者不可用时）
代理节点（如 gh.dpik.top） 无 测速，下载测试资源
addon-analytics.hubp.org 匿名聚合计数 提交匿名统计数据用于汇总
addon-analytics-hubp.tbedu.top 匿名聚合计数 备用统计地址（主源不可用时使用）
